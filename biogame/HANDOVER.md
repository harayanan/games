# Body Sticks — Handover

## Status

Playable. 500 sticks across 10 body systems. Served as part of Shakti's website at
`/games/body-sticks/` (see `../../shakti-website`). Live at https://shakti-website.harayanan.workers.dev/games/body-sticks/

The mechanics follow Chalk & Chuckles' *Smart Sticks: Medical Science*: spin a 3-colour
wheel, draw a stick of that colour, first correct answer wins the stick, 5 sticks
wins. All questions are original.

## Layout

```
public/index.html        shell
public/app.js            game engine (vanilla JS, no build)
public/style.css
public/data/sticks.json  GENERATED by scripts/build.mjs — do not edit by hand
content/<system>.json    source questions, 50 per system
CONTENT-SPEC.md          schema + writing rules for questions (use for the next batch)
scripts/build.mjs        validates content/*.json and writes public/data/sticks.json
```

## Run locally

```bash
npm run dev     # validates content, then serves public/ on http://localhost:9125
```

## Game design

- **Modes:** green = Odd One Out (5 items), red = Don't Say It (taboo), blue = Doctor's
  Decision (patient case, 4 options).
- **Solo:** tap answers. Taboo becomes a clue puzzle: one clue at a time, guess from
  the word + 3 decoys. Win 5 sticks to finish a round.
- **With friends (2–4, one screen):** anyone taps their name to answer. A wrong answer
  locks that player out for the stick. On taboo, the spinner describes against a
  60-second timer and taps whoever guessed it.
- **Every stick shows the explanation** after it is answered, right or wrong.
- **Spaced repetition** (`drawStick` in app.js): missed sticks come back after about 6
  draws, unseen sticks come next, and correct sticks return after a gap that doubles
  each time.
- **Body map:** organs fill in as sticks are learned. Tap a system to open the
  "doctor's notebook" of learned explanations.
- **Progress** is stored per device in localStorage (`bs.progress`, `bs.clock`,
  `bs.settings`, `bs.names`).

## Adding the next 500 sticks

1. Follow `CONTENT-SPEC.md`. Either add a second file per system (e.g.
   `content/heart-2.json` — needs a small change to build.mjs, which currently maps
   file name to system id) or append to the existing files with ids `-018` onward.
   Ids allow 2–3 digits.
2. Run `node scripts/build.mjs`. It fails on schema errors, duplicate taboo words, and
   forbidden words inside clues.
3. Rebuild and redeploy the website (`npm run deploy` in shakti-website).
4. The home screen shows "You have seen all N sticks" once every stick has been seen.

## Content review notes

- Writers flagged and fixed odd-one-outs that had two defensible answers. They also
  removed facts they weren't sure of (surface-area comparisons, the "80% of flavour"
  figure, the dengue vaccine status in India).
- Some concepts appear in more than one mode (for example "Cerebellum" as an odd item,
  a taboo word and a case answer). This is deliberate: each mode tests the concept
  from a different angle.
